# BuildWise AI — Option 1 prototype

## Run locally
1. Install Python 3.10 or newer.
2. Open a terminal in this folder.
3. Run `python -m pip install -r requirements.txt`
4. Run `streamlit run app.py`
5. Open the local URL shown in the terminal.

## Included
- Three project inputs: building type, location and plot area.
- Suggested floor options based on explicit placeholder assumptions.
- Schematic 2D architectural plan with labeled room zones, overall dimensions and schematic openings.
- Coordinated conceptual grid and element IDs for columns, beams, slabs and foundations.
- Educational standalone beam shear-force and bending-moment diagrams.
- Selectable element categories and schematic section illustrations.
- Preliminary area-based quantity/cost allowances.
- PNG, CSV and text exports.

## Limitations
Academic prototype only, not a code-compliant design system. Plot geometry, road/north orientation, setbacks, soil data and local rules are not verified. Element sizes and material quantities are placeholders. The beam calculation is not a full building analysis. Do not use outputs for construction; obtain qualified architectural and structural review.
